# Dataset provenance

81 hand-authored synthetic preference votes across 27 categorical contexts; three votes per context encode designer disagreement, not real users or statistical sampling. Created for this prototype on October 10, 2026. No scraped material, private data, or outdoor measurements. All data is MIT licensed along with the code. Do not report training-set fit as real-world accuracy. Energy/setting preferences are illustrative design choices, not health advice.
